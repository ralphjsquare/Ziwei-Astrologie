3. “现代整理”类（红鸾、天喜）没有古籍引文，是通行说法。
4. 所有解释文字遵循“传统说法 + 概率性措辞”，不做绝对化断言；如有不当请在审核意见中指出。
5. 本包只反映本项目的取舍，不是对各神煞灵验与否的判断。
