# ADR-016 神煞第二批（共 28 种）

状态：采纳（2026-09-29）。表格均取自《三命通会》卷三、卷六语料；与 bazi-lite 逐柱比对（1200 盘）。

## 新增 17 种
月德贵人、月德合、德秀贵人、元辰、灾煞、勾煞、绞煞、十恶大败、天罗、地网、三奇贵人、禄神、魁罡、日德、日贵、丧门、吊客。

## 与原文或参照实现的差异及处理
- **十恶大败**：原文日柱列表写作“乙丑”，但按原文自己的判据（日干之禄落入旬空）应为**己丑**，通行表与 bazi-lite 也是己丑；本项目取己丑，规则引文避开该列表。
- **绞煞**：原文“命后一三辰为绞”疑为“命后三辰”之误；按其举例（甲子阳命人，酉为绞）与 bazi-lite，取后三位。
- **德秀贵人**：原文只列出各三合局的“德”干与“秀”干，未说明是否须两者同见；本项目与 bazi-lite 一致，某柱天干属于当月的德或秀即列出，并注明是德还是秀。
- **三奇贵人**：原文强调“顺布”，但也说“不得顺布亦有取用”；本项目与 bazi-lite 一致，只要三个天干都出现就列出，并标注是否依序相连。
- **天罗、地网**：按原文“男怕天罗，女怕地网；火命有天罗，水、土命有地网”，命以年柱纳音五行计，戌亥（辰巳）须同见。bazi-lite 对命的五行取法与原文不一致（另一实现），故这两项没有独立参照，只有据原文手写的测试。

## 未纳入（原文不足或与通行说法不一致）
天德/天德合（原文只给出数个月份）、太极贵人（壬癸一段含混）、文昌贵人（原文歌诀与通行表不一致且有讹字）、学堂词馆（依纳音，判据复杂）、红鸾天喜（语料中没有对应的表；语料里的“天喜”是另一种说法）。
