# ADR-002 支持年份与历法核对
状态：已采纳（D02-A）。支持 1901–2100，超出范围抛出 `OutOfRangeError`，不静默给出结果。1900 年不承诺。

**环境限制（如实记录）**：本项目构建环境的网络代理拦截了香港天文台（www.hko.gov.hk，403），因此**未能**与其公布的 1901–2100 农历对照表逐日核对。替代做法：
1. 用独立的天文推算（`astronomy-engine`：朔日按 UTC+8 取日，以冬至月为十一月，无中气月置闰）重新推导 1901–2100 全部 2468 个农历月，与历法库 `tyme4ts` 比对，仅 4 例不一致，均已裁决（见 ADR-008）。
2. 公农历往返、日干支连续性对 1901–2100 每一天全枚举。
**待办**：在可访问 HKO 的环境中补做逐日核对（把 HKO 文本数据转成 JSON 后加一个测试即可）。
