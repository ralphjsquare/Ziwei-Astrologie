# ADR-003 出生地时区与夏令时
状态：已采纳（D03-A，含补充约束）。
- **引擎只接收明确偏移**：`place.utcOffsetMinutes`（钟表时间相对 UTC 的总偏移，含夏令时）与 `place.dstMinutes`（其中夏令时部分，排盘时扣除）。引擎不读取运行环境的时区数据库，以保证 Node 与浏览器结果逐字节一致。
- 网页默认“中国大陆 UTC+8”；1986–1991 年夏令时由 `src/calendar/china-dst.ts` 预填。该表与 Node 内置 IANA 数据（ICU）**逐日核对**，核对中发现并修正了 1988 年起始日（应为 4 月 17 日，最初误为 4 月 10 日）。拨钟当日的“不存在”与“重复”小时会给出提示而不是猜测。
- 1949 年以前及非中国大陆出生时间的时区规则，界面提示“按您给出的偏移计算，可能与当时实际采用的时间不一致”。
- 真太阳时：默认关闭；必须提供经度，缺经度时开关禁用并报错，不使用默认经度。
- 真太阳时只影响时辰与日界判定；节令比较使用绝对时刻（UTC）。
