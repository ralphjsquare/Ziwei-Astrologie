# ADR-023 白话解读报告（可理解性与可读性）

状态：已采纳（用户要求以可理解性和可读性为最高优先级）

## 做法
- 新增「白话报告」页（`src/interpret/report.ts`、`web/main.ts`）：把排盘事实与已有规则的要点，写成一篇可连续阅读的文字——先说怎么读、一眼看懂、性格与气质（取象）、生活各方面、出生年四化、眼下（可选年份）、延伸阅读（《渊海子平》相关条目）、最后几句。
- 每个段落带来源标记：排盘事实（可复核）／传统说法／现代通行说法／说明；带规则的段落可展开“出处与审核状态”。
- 术语第一次出现时加虚线下划线与悬停解释（名词小词典）；字号可调（A−／A＋，记在本机）；目录跳转；导出 Markdown；打印／存为 PDF（打印时隐藏操作区与出处折叠）。
- 约束不变：不新增断语、不做综合评分、不下指令、全部“未审核”；`test/report.test.ts` 对 80+ 个盘检查语言准则与评分类用语，并核对用户盘的事实。

## 不做
- 简明／详细切换（用户未选）；综合评分（既定原则）；用大语言模型现场生成文字（结果不可复现、无法保证不编造出处）。

## 局限
- 文字由模板与规则拼成，读起来比人工写的生硬；不了解当事人的真实经历。
- 辅星、杂曜、六亲与女命相关内容尚无规则，报告中不涉及。

## 补充：解读文本库（2026-10-25）
首版报告只是规则要点的重排，缺少真正的解读。改为：由项目整理一套现代白话文本库（`src/interpret/reading-data.ts`：十四主星的做事风格／优势／留意点，十神的取象与缺失说法，四化与大运流年主题），程序按盘面把两套体系综合成连贯文字——一句话读你的盘、紫微与八字的共同点或差异、你是什么样的人、事业与财务、感情与家庭、内心与身体、变化点、眼下。
- 这套文字是“现代通行说法”，由项目作者撰写，未审核，不是古籍原文；段落旁可展开相关古籍条目作对照。
- 语言仍是“较有可能”口吻；不下断语、不评分、不下指令；空宫借对宫；同一颗星只在首次完整介绍，后文从简以免重复。
- 测试：80+ 个盘的语言准则与占位符检查（`test/report.test.ts`）。

## 补充：“怎么用”对应在每段解读之后（2026-10-27）
用户要求应用建议对应在解盘的各部分，而不是集中在一节。现改为：命宫、日主旺衰、十神、十神缺失、配偶宫、五行、各宫（事业、财务、感情、子女、家宅、长辈、内心、身体）、四化、化忌对宫、人生十年一页、大限、大运、流年和流年四化，每段解读后面紧跟一段“怎么用”（界面用绿色标记区分）；原来的集中小节缩成“几个可以自己想一想的问题”。
语言边界不变：自我观察与日常习惯层面的参考，不替人做决定；疾厄宫单独处理，并提示“身体有不适时请咨询专业医生”。

## 补充：“怎么用”结合相关宫位（2026-10-27）
用户要求“怎么用”要结合所有相关宫位。现改为按生活领域综合：事业（官禄＋三方四正＋迁移、交友、福德）、财务（财帛＋三方四正＋田宅、福德）、感情（夫妻＋三方四正＋命宫、福德）、家庭与晚辈（田宅＋三方四正＋子女、父母、兄弟）、身心状态（疾厄＋三方四正＋福德、命宫）。每个领域依次给出：
1. 连起来的宫位及各宫主星（空宫借对宫），主星取象的重心；
2. 本命、大限、流年四化在这些宫里的落点（好处与需留意处并见时说明“起伏明显”）；
3. 八字对应（相关十神类别的数量与含义，如事业看官杀、食伤、财，感情看配偶宫与配偶星）；
4. 一段“怎么用：综合这几个宫位”——发挥（主星优势）、留意（化忌或盲点）、节奏（大限、流年是否正走到这些宫）、八字上的补充。
原先逐宫的“怎么用”改为并入领域综合；命宫、日主、十神、五行等处的“怎么用”保留。三方四正按宫序（命、兄、夫、子、财、疾、迁、友、官、田、福、父）的三合与对宫计算。
