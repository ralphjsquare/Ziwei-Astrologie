# ADR-020 外部成熟软件对照验证（用户本人命盘）

状态：已采纳

## 背景
用户提供 1988-04-02 07:50（北京时间）男命，在吉真紫微与问真八字中的排盘截图，作为外部对照。
期望值转录于 `test/user-case.test.ts`（来源是外部软件，不是本引擎输出）。

## 结果
- 紫微：阳男水二局、命宫癸亥、身宫己未、全部主辅星落宫、庙旺、四化、大限起岁、小限、流斗——一致。
- 八字：四柱、纳音、藏干、十神、星运、各柱空亡、截图可见神煞——一致（下列差异修正后）。

## 发现的差异与处理
1. 缺命主／身主：新增（命主按命宫地支、身主按年支）。
2. 缺各柱旬空：新增 `kongWangByPillar`，界面加「旬空」行，解读同时报日柱与年柱旬空。
3. 将星／华盖／暗金煞：外部软件不以「本柱自身」为基准给本柱记该神煞，引擎改为同样处理。
   这是约定选择，基柱本身不计；`test/shensha.test.ts` 对 bazi-lite 的比对相应容忍此类差异。
4. 文昌贵人默认取《三命通会》表（丁→辰），常见软件取丁→酉。保留默认，可由选项 `wenchangMode` 切换，非缺陷。

## 未实现（外部软件有而本系统无）
长生十二神、博士十二神、将前／岁前十二神、杂曜、子斗、自坐行；右弼／魁钺／天马的庙旺。
未经用户要求，不做。

## 第二个盘（2026-10-03）
1993-11-21 北京时间16:15（软件真太阳时16:06）申时，农历癸酉年十月初八。转录于 `test/user-case2.test.ts`。
- 紫微：水二局、命宫乙卯、身宫己未、命主文曲、身主天同、十二宫星曜与庙旺、四化（破军禄巨门权太阴科贪狼忌）、大限起岁、小限（1993虚1岁在未、逆行）——一致。
- 八字：四柱、纳音、星运、各柱空亡、十神、软件可见神煞——一致。
- 差异（非缺陷）：
  1. 文昌贵人：软件取通行表（丙→申），本系统默认取三命通会表，选「通行表」后一致。
  2. 软件把时柱申标为「词馆」；本系统按日干丙长生在申标为「官贵学堂」，临官在亥（月柱）标「官贵词馆」，见 ADR-018，属命名约定差异。
  3. 本系统多出的绞煞、六厄、官贵学堂／词馆，在截图中未显示。
- 性别：首张八字截图因默认值误输入为男（乾造），用户已重新输入为女（坤造）；第二张八字截图与本系统女命结果一致。
- 未实现项同上节（长生／博士／岁前十二神、子斗、杂曜）。

## 大运对照（2026-10-03）
问真八字「专业细盘」两个盘的起运与大运，转录于 `test/user-case2.test.ts`：
- 1993 女：起运5年3月2天7时，1999年交运，甲子→乙丑→丙寅…顺行；1988 男：起运0年10月8天16时，1989年交运，丙辰→丁巳→戊午…顺行。大运干支、起运岁数与交运年份均一致。
- 起运精确到日、时的数值，软件按其显示的**真太阳时**（16:06、07:55）起算；本系统按填入的钟表时间起算。同样输入 16:06／07:55 时与软件逐位一致，输入 16:15／07:50 时相差数小时至一天内，不是算法分歧。如需与软件对齐，请填真太阳时，或启用本系统的真太阳时设置。
