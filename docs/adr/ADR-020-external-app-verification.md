# ADR-020 外部成熟软件对照验证（用户本人命盘）

状态：已采纳

## 背景
用户提供 1988-04-02 07:50（北京时间）男命，在吉真紫微与问真八字中的排盘截图，作为外部对照。
期望值转录于 `test/user-case.test.ts`（来源是外部软件，不是本引擎输出）。

## 结果
- 紫微：阳男水二局、命宫癸亥、身宫己未、全部主辅星落宫、庙旺、四化、大限起岁、小限、流斗——一致。
- 八字：四柱、纳音、藏干、十神、星运、各柱空亡、截图可见神煞——一致（下列差异修正后）。

## 发现的差异与处理
1. 缺命主／身主：新增（命主按命宫地支、身主按年支）。
2. 缺各柱旬空：新增 `kongWangByPillar`，界面加「旬空」行，解读同时报日柱与年柱旬空。
3. 将星／华盖／暗金煞：外部软件不以「本柱自身」为基准给本柱记该神煞，引擎改为同样处理。
   这是约定选择，基柱本身不计；`test/shensha.test.ts` 对 bazi-lite 的比对相应容忍此类差异。
4. 文昌贵人默认取《三命通会》表（丁→辰），常见软件取丁→酉。保留默认，可由选项 `wenchangMode` 切换，非缺陷。

## 未实现（外部软件有而本系统无）
长生十二神、博士十二神、将前／岁前十二神、杂曜、子斗、自坐行；右弼／魁钺／天马的庙旺。
未经用户要求，不做。
