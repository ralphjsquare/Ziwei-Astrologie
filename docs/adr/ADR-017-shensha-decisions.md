# ADR-017 神煞取舍定稿（依 `SHENSHA_DISCUSSION.md` 的确认稿）

状态：采纳（2026-09-29）。确认稿来自 GPT 的书面意见，经用户转交；文本核对结论我用本地的 Kanripo 文渊阁四库全书本复核过（T1–T4，见 `docs/sources/textual-variants.json`）。确认稿提到的《古今图书集成》引文我没有能力核对，不作为依据。

## 总原则
1. 古籍能明确推出的规则为默认。2. 古籍有异文但其他传本可校正的，保留古籍规则并记录异文。3. 古籍无依据、现代通行的可收，但必须标“现代整理”，且放在独立 namespace（`modern_shensha.*`），不得附古籍引文。4. 不同流派都有稳定实现的，做显式配置项。5. 判据本身未定的暂缓。6. “检测到”与“完整成立”分层记录。

## 逐项决定
| 项 | 决定 |
|---|---|
| S1 天德、天德合 | 收全表。来源写“前四个月逐项有文字，其后原文写‘余照此’，依原排列推演，与通行表及两个实现一致”。 |
| S2 文昌贵人 | 默认《三命通会》歌诀表（甲巳乙亥丙戌丁辰戊申己午庚寅辛未壬卯癸丑），选项 `wenchangMode: 'common'` 切换通行表。四库本作“甲人蛇口乙猪头”，故语料“甲乙蛇口”为转录异文。 |
| S3 太极贵人 | 收全表，壬癸取申、巳（四库本作“先得申而生”）。 |
| S4 红鸾、天喜 | 年支系，收为 `modern_shensha.*`（MODERN_COMMON，无引文）；与原文季节式“天喜神”是不同规则。语料中“春戊”为“春戌”之误，仅记异文。 |
| S5 学堂词馆 | 当时暂缓；后已按专题完成，见 ADR-018。 |
| S6 羊刃阴干 | 默认关闭；选项 `yinStemYangRen`，开启后按禄后一位（乙寅丁巳己巳辛申癸亥），标注“另一流派”。 |
| S7 德秀 | 保持单见即列出；`qualified` 记录德、秀是否同见。 |
| S8 三奇 | 保持检测到即列出；`qualified` 记录是否顺布。 |
| S9 其余神煞 | 逐项先查语料，有表的才补；不为数量追赶 bazi-lite。 |

## 架构
- 规则新增 `sourceClass`：`PRIMARY_TEXT` / `TEXTUAL_VARIANT` / `CLASSICAL_SECONDARY` / `MODERN_COMMON` / `IMPLEMENTATION_ONLY`。`validateRules` 要求所有神煞规则必须标注，`MODERN_COMMON` 与 `modern_shensha.*` 不得附引文。
- 命中记录 `ShenShaHit` 增加可选 `qualified`（仅德秀、三奇使用）。
- 验证：与 bazi-lite 逐柱比对 1200 盘（天德、天德合、太极、红鸾、天喜、通行表文昌、开启阴干后的羊刃）一致；歌诀表文昌、天德逐月、太极、红鸾天喜另有手写期望。
