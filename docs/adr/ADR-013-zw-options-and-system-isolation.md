# ADR-013 紫微冻结口径与两套体系隔离

状态：采纳并冻结（2026-09-29，按用户定稿）。取代此前“增加 `decadeStart: literal` 选项”的设想（已撤销，代码中不再有该选项）。

## 冻结口径
```
LEAP_MONTH_RULE       = midMonth     DECIDED / KEEP CURRENT DEFAULT
FIRST_MAJOR_LIMIT     = 命宫
MAJOR_LIMIT_DIRECTION = 阳男阴女顺，阴男阳女逆
```
1. **闰月**：闰月初一至十五按本月，十六日至月底按下月。理由：与 iztro `fixLeap=true`（默认）一致，便于回归与预期。`currentMonth`、`nextMonth`（《全书》“闰月一律按下月”字面法）仅作可选配置，不覆盖默认；界面对闰月出生者提示“不同流派可能产生不同命盘”，并用例子说明（闰四月初十按四月，二十按五月）。
2. **大限**：首限自命宫起，起限岁数由五行局定（水二 2–11、木三 3–12、金四 4–13、土五 5–14、火六 6–15）；阳男阴女顺行、阴男阳女逆行，每十年一宫。即阳男阴女：命宫→父母→福德…；阴男阳女：命宫→兄弟→夫妻…。
3. **《全书》大限诀的“命前一宫/命后一宫”**：不解读为首限落父母宫或兄弟宫，而理解为第二限起的行宫方向描述；软件不据此把首限移出命宫。用户界面只写：“大限首限自命宫起，起限年龄按五行局确定。阳男阴女顺行，阴男阳女逆行；第二限开始依顺逆方向逐宫移动。”古籍原文放在出处/注释中。若首限落在父母/兄弟宫，视为回归失败。
4. **八字不设闰月规则**，不受任何紫微选项影响：年柱按立春，月柱按十二节交节时刻。八字可配置项是日界、真太阳时、大运起运，不与紫微混算（`test/variants.test.ts` 有隔离测试）。

## 黄金/回归要求（已在 `test/variants.test.ts` 落实，期望值来自 iztro，不取自引擎）
- 闰月十五日、十六日各 20 例以上：`midMonth` 分界（15 日本月、16 日下月）并与 iztro 盘面一致；三种规则对闰月初十/二十各对应 iztro 的口径。
- 大限：五行局、首限年龄、首限宫位=命宫、顺逆方向、第二限宫位；阳男、阴男、阳女、阴女全部覆盖；各宫大限年龄与 iztro 一致。
