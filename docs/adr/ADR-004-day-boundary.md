# ADR-004 子时与日界
状态：已采纳（D04-A）。八字日柱换日、紫微农历生日换日分别配置，均为 `zi23`（23:00 起算次日）或 `zi00`（00:00 起算次日），**默认均为 `zi23`**（与通行软件对晚子时的处理一致）。时辰以整点为界，23:00 起为子时，边界时刻归后一时辰。

字段变化表（2024-05-15，`test/calendar.test.ts` 中固化）：

| 钟表时间 | 时辰 | 八字日柱日期 zi23 / zi00 | 晚子时 |
|---|---|---|---|
| 22:59 | 亥 | 15 / 15 | 否 |
| 23:00 | 子 | 16 / 15 | 是 |
| 23:59 | 子 | 16 / 15 | 是 |
| 次日 00:00 | 子 | 16 / 16 | 否 |
| 次日 00:59 | 子 | 16 / 16 | 否 |
| 次日 01:00 | 丑 | 16 / 16 | 否 |

八字时干：`zi23` 时晚子时用次日日干起五鼠遁；`zi00` 用当日日干。
**与 iztro 的已知差异**：iztro 处理晚子时只把“日”推后一天而月份不变；本项目按次日完整农历日期处理。差异只出现在晚子时恰逢农历月末（次日跨月）或闰月时，已在测试中记录并限定（`test/ziwei.test.ts`）。其余情形一致。
