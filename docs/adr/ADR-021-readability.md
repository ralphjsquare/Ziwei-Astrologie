# ADR-021 面向普通人的可读性功能

状态：已采纳（用户选定：总览、名词释义、图形；不做简明／详细分层，不做综合评分）

## 内容
1. 「一页读懂」（`src/interpret/summary.ts`）：把命盘事实与已有规则的要点按主题归拢——先看这几件事、生活各方面、四化、十神分布、眼下走到哪一步。
   - 每个要点由“排盘事实”＋“规则里已有的 data 短语／现代通行取象”拼成，附原规则条目，可展开看出处与审核状态。
   - 不新增断语；不合并为“整体运势”；`test/readable.test.ts` 对 60+ 个盘检查语言准则，并禁止出现评分类用语。
2. 名词小词典（`src/rules/glossary.ts`）：只写词在排盘里指什么（算法与通行定义），不含吉凶、不引古籍。命盘页的术语以虚线下划线显示，悬停可见；另有「名词」页可搜索。十神释义另有独立写法的测试核对。
3. 图形（`web/charts.ts`，数据来自 `src/interpret/stats.ts`）：五行数量（两种口径）、十神数量、八字大运与紫微大限时间轴。
   - 单色条形、直接标数值、附数据表；只描述数量与区间，不表达强弱好坏。

## 不做
- 简明／详细切换（用户未选）；综合评分（既定原则）。

## 局限
- 名词释义与总览文字同样是“未审核”，需专业人士核对。
- 辅星、杂曜的释义尚未收录（沿用“暂未收录”提示）。
