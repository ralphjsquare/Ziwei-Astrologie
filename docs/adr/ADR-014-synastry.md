# ADR-014 合盘（两人并列对照）

状态：采纳（2026-09-29）。

## 范围
- 输入两个人的完整命盘（各自独立计算，选项可不同），输出结构性并列对照，**不打分、不做“合不合”判断**。
- 紫微与八字各自独立，不互相混算；八字部分：日主十神与天干合冲、日支关系、年支（属相）关系、跨盘合冲刑害、五行个数并列；紫微部分：命宫互落与地支关系、夫妻宫与对方命宫、年干四化落入对方盘。
- 规则文本全部为 `draft`：位置与关系类型是算法事实（structural）；解释是现代通行整理（modern），没有古籍引文，不冒称古籍。
- 未纳入：合婚打分、八字纳音合婚、飞星派互化、流年合盘（后续可加）。

## 关系类型口径
六合、六冲、六害、三合沿用 `src/bazi/tables.ts`（ADR-011）；“三合”在命宫对比中指两个地支属于同一三合局。
