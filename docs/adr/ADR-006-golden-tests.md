# ADR-006 黄金测试与预言来源
状态：已采纳（D06-A）。核心原则：**期望值不得来自本项目引擎自己的输出。**

| 层 | 实现情况 |
|---|---|
| L1 历法 | 已完成。1901–2100 每一天：公农历往返、日干支连续；4799 个节气与天文推算相差 ≤90 秒；2468 个农历月与天文推算对照（4 例已裁决） |
| L2 安星表 | 部分完成。紫微星位置：经典表格行（水二局、木三局初一至初十）+ 全枚举合法性/整除性质；天府对称全枚举。**未能**把《全书》表格录入为独立查表实现（公版语料未入库，见 ADR-007），改由与 iztro 的大规模差分比对承担（该比对已发现并修正天魁天钺“辛年”的错误） |
| L3 整盘 | 60 个出生输入（闰月、子时、立春、春节先后、节令交接、范围两端、农历三十、夏令时、覆盖矩阵），期望值来自 iztro（紫微）与 tyme4ts（八字），与引擎零分歧；每例记录 `oracle`。**人工签字 20 盘尚未完成**：核对表见 `docs/golden/HUMAN_REVIEW_SHEET.md`，需确认人（本人或老师）逐盘核对签字，工时不计入 API 预算 |
| L4 性质 | 已完成（fast-check：十二宫、星曜唯一、紫微天府对称、大限连续、哈希键序无关、旺衰范围等） |

另有随机差分：紫微 300 盘、流年/流月/大限 40 盘×4 流月对 iztro；八字 3000 盘 + 节令前后 ±2 分钟对 tyme4ts；三处独立实现均为开源软件，**其一致不等于古籍正确**，只是发现差异的手段（计划 4.1 原则）。
名人盘不作为黄金盘（出生时间无法独立确认，且涉及隐私）。
