# ADR-015 功能缺口补充：小限、庙旺利陷、调候、神煞

状态：采纳（2026-09-29）。全部规则文本为 `draft`；引文均来自语料，不手写古籍原文。

## 小限
- 依《紫微斗数全书》卷二“安小限诀”：出生年支定虚岁 1 岁起宫（寅午戌辰、申子辰戌、巳酉丑未、亥卯未丑），男顺女逆，每年一宫。
- 对照 iztro 每宫 `ages`：300 盘 × 虚岁 1–100 逐一致。结果在流年层 `minorLimit`，解读页新增“当年小限”。

## 庙旺利陷
- 亮度表由 `tools/gen-brightness.ts` 从卷二“诸星庙旺利陷表”（维基文库转录的 ASCII 表）解析生成 `brightness.generated.ts`；有测试保证生成文件与转录本一致。
- 表含 21 颗星（十四主星、昌曲、火铃、羊陀、禄存）；对照 iztro 的 222 个星×宫组合一致（iztro 不给禄存定等级，不比较）。命盘星曜上显示等级，解读页新增“主星庙旺利陷”，等级含义为通行整理（school，draft）。

## 调候
- 语料来自用户提供的《穷通宝鉴》txt（版本未核实，已接受并逐条标注）。只摘录“日主×月份”条目的开头一至三句原文（117/120 条；原书电子本缺乙丑、戊子、戊丑），在解读页“调候参考”中引出。
- **不做自动“用神提取”**：试验过机械提取首句中的天干，与参照实现（zhiji-bazi 的简化表）首选元素只有约一半一致，说明首句里的天干并不总是取用之神；因此只展示原文，不下结论，也不进入任何评分。

## 神煞
- 选十一种：天乙贵人、驿马、咸池（桃花）、劫煞、亡神、将星、华盖、羊刃、金舆、孤辰、寡宿。表格来自《三命通会》卷二、卷三、卷六的文字。
- 三合类以年支、日支为基准；天乙贵人以日干、年干；羊刃、金舆以日干；孤辰寡宿以年支。（2026-10-02 起：将星、华盖、暗金煞不计基准柱自身，见 ADR-020。）
- 对照 bazi-lite：1500 盘、十种神煞的四柱分布一致；羊刃仅比较阳干——《三命通会》明确“五阴干无刃”，bazi-lite 另有阴干羊刃（不同流派），不比较。
- 只列位置，不打分；解读文字均含“传统说法”“并不代表”类措辞。
- 未纳入：红鸾天喜、天德月德、文昌、学堂、魁罡等其余神煞（后续可加）。
