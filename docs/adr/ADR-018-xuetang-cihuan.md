# ADR-018 学堂词馆专题（《三命通会》卷三“论学堂词馆”的 5 类）

状态：采纳（2026-09-29）。用户决定：全部做，原文只给例子的部分“按逻辑接受反推”。

## 基准的选择
- “命”（如“金命”“己酉人”）：取**年柱纳音五行**（原文“己酉人得丙子”以年柱称人，且 bazi-lite 同）。
- “甲乙人”“丙丁人”等按天干分组：对日干、年干**两个基准分别列出**，命中记录里注明基准；与 bazi-lite 比对时只比日干基准。

## 七条规则
| 规则 | 判据 | 来源分级 |
|---|---|---|
| 正学堂 | 年柱纳音五行的长生位（金巳木亥水土申火寅），且该柱纳音同五行 | PRIMARY_TEXT |
| 正词馆 | 临官位（金申木寅水土亥火巳），且该柱纳音同五行 | PRIMARY_TEXT |
| 官贵学堂（学堂会禄） | 日干（年干）五行的官星五行之长生位 | PRIMARY_TEXT |
| 官贵词馆 | 同上之临官位 | PRIMARY_TEXT |
| 官星学堂 | 五行长生位加一个克它的干：辛亥、壬寅、甲申、丁巳（原文）；壬癸→戊申（据规律反推，与 mingyu-core 一致） | DERIVED_FROM_TEXT |
| 食神学堂（学堂会食） | 日干的食神干配其五行长生位，阴阳不配时取临官位：甲丙寅、乙丁巳、丙戊申（原文），其余反推 | DERIVED_FROM_TEXT |
| 学堂会贵 | 年柱纳音的帝旺位，且是年干或日干的天乙贵人；例子在日、时，故只查日柱、时柱 | DERIVED_FROM_TEXT |

## 成色
原文“切不要犯空亡及冲破，支干纳音不要见克，方为得用”“要有马”。实现：落日柱旬空或被其他柱冲，则 `qualified=false` 并写明；命局带驿马只作说明。“纳音不要见克”“要乘旺”判据不明，未实现。

## 不收
- 日干学堂、日干词馆（bazi-lite 自加，原文无）。
- 原文“诸家说”里引用的《祝胜经》“甲辰丙寅，学堂不真”等，属评语而非判据。

## 验证
- 与 bazi-lite 比对 1500 盘：正学堂、正词馆、官贵学堂、官贵词馆（日干基准）、学堂会贵（日时柱）一致。
- 官星学堂与 mingyu-core 的表一致（含壬癸戊申）；食神学堂的甲乙丙丁庚辛与 mingyu-core 一致，戊己壬癸为本项目反推（mingyu-core 未收）。
- 手写测试：原文例子（金命辛巳、壬申，己酉人丙子，壬午人辛卯）及成色。
