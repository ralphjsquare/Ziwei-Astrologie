# ADR-010 紫微数据表与已知差异
状态：已采纳。表数据集中于 `src/ziwei/tables.ts`，出处为《紫微斗数全书》安星诀的传统说法（篇目级，未核对原文）。
- 命宫/身宫：寅起正月顺数至生月，逆/顺数至生时；宫干五虎遁；五行局取命宫干支纳音；紫微星商余法；天府与紫微对称于寅申轴；六吉六煞及禄存、天马、红鸾、天喜。
- **四化**：默认《全书》通行版本；戊（2 种）、庚（4 种）、壬（2 种）、癸（2 种）的并行版本做成选项 `sihua`，与 ziwei-lite 的各版本逐一核对一致（`test/triangulation.test.ts`）。版本取舍待古籍核对。
- **辛年天魁天钺**：口诀“六辛逢马虎”与“六辛逢虎马”并存。iztro 取魁午钺寅（本项目默认，`kuiYueXin: 'ma-hu'`），ziwei-lite 取魁寅钺午（`'hu-ma'`）。**本项目最初曾把它当作“错误”修正，三方印证后确认是并存的传统说法**，两说均可由选项复现。
- 大限：阳男阴女顺行，阴男阳女逆行；起限岁数为五行局数；虚岁。
- 流月：斗君法，已与 iztro 对照一致。
- 与 ziwei-lite 的其余差异：无（400 个随机盘，二十六颗星落宫、局、身宫、宫干、生年四化全部一致，辛年魁钺除外）。
- 未实现：庙旺利陷、小限、三台八座等杂曜、飞星四化。
