# ADR-010 紫微数据表与已知差异
状态：已采纳。表数据集中于 `src/ziwei/tables.ts`，出处为《紫微斗数全书》安星诀的传统说法（篇目级，未核对原文）。
- 命宫/身宫：寅起正月顺数至生月，逆/顺数至生时；宫干五虎遁；五行局取命宫干支纳音；紫微星商余法；天府与紫微对称于寅申轴；六吉六煞及禄存、天马、红鸾、天喜。
- 四化：《全书》通行版本（甲廉破武阳，乙机梁紫阴，丙同机昌廉，丁阴同机巨，戊贪阴弼机，己武贪梁曲，庚阳武阴同，辛巨阳曲昌，壬梁紫辅武，癸破巨阴贪）。个别天干存在版本差异，v1 只提供这一版。
- 天魁天钺：“甲戊庚牛羊，乙己鼠猴乡，丙丁猪鸡位，壬癸兔蛇藏，六辛逢马虎”。**曾经把辛年的魁钺写反，被与 iztro 的差分测试发现并修正。**
- 大限：阳男阴女顺行，阴男阳女逆行；起限岁数为五行局数；虚岁。
- 流月：斗君法（流年太岁宫起正月逆数至生月，再顺数至生时为斗君，即流年正月，顺行）。已与 iztro 对照一致。
- 未实现：庙旺利陷、小限、三台八座等杂曜、飞星四化。
