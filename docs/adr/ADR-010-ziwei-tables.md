# ADR-010 紫微数据表与已知差异
状态：已采纳。表数据集中于 `src/ziwei/tables.ts`。**一手依据**：《紫微斗数全书》卷二原文（维基文库转录本，`docs/sources/raw/zwqs/`，已入语料库），由 `test/canon-quanshu.test.ts` 逐项核对（底本未核对，见 ADR-007）。

## 依据原文裁定的默认值（与部分软件不同，均可用选项切换）
1. **辛年天魁天钺**：原文“六辛逢**虎马**”→ 魁寅钺午（`kuiYueXin: 'hu-ma'`，**默认**，与 ziwei-lite 一致）。iztro 取“马虎”（魁午钺寅），用 `'ma-hu'` 复现。
2. **壬年四化**：原文“壬梁紫**府**武宿是”→ 天梁禄、紫微权、天府科、武曲忌（`sihua.壬 = 1`，**默认**）。通行软件多取“左辅”科（`sihua.壬 = 2`）。
3. 戊、庚、癸年及其余天干：原文与通行版本一致；各软件并存的其他版本（戊 2 种、庚 4 种、癸 2 种）保留为选项。

## 原文/转录中的已知问题（交审核人对照影印本）
- **丙丁“猪狗位”**：原文写作“猪狗”，而其余所有软件与常见版本均为“猪鸡”（亥、酉）；疑为转录之误，本项目取“亥、酉”。
- **木三局紫微落宫表**：寅宫写作“初三、初九”，而初九已在辰宫，算法给出寅宫应为“初三、初五”；疑为原书或转录之误（初五漏写、初九重出）。
- **金四局表**未列“三十”日（算法：落亥宫，与“初一”同宫）。
- **大限诀措辞**：原文“安大限诀：阳男阴女从命前一宫起顺行 是父母宫；阴男阳女从命后一宫起逆行 是兄弟宫”，字面似指起于命宫的前（后）一宫；本项目与 iztro、ziwei-lite 一致，按通行做法**自命宫起限**（局数为起限岁数）。此处理解待审核人裁定。
- **闰月**：原文“又若闰月正月生者要在二月内起安身命，凡有闰月具要依此为例”，字面为**闰月一律按下月**（`leapMonthRule: 'nextMonth'`）。本项目默认沿用 iztro 与 ziwei-lite 一致的“月中分界”（十五日前按本月、后按下月，`'midMonth'`），原文说法可用选项复现，**默认取舍待审核人裁定**。

## 其他
- 大限：阳男阴女顺行，阴男阳女逆行；起限岁数为五行局数；虚岁。
- 流月：斗君法，按**农历月序**推进，闰月不单列。已与 iztro、ziwei-lite（其 `EFFECTIVE_MONTH` 策略）对照一致；ziwei-lite 默认按“含闰月的时序”，两者只在当年有闰月时不同。
- 与 ziwei-lite 的差异：无（400 个随机盘，二十六颗星落宫、局、身宫、宫干、生年四化一致；壬年与 ziwei-lite 的第 2 版对应）。
- 未实现：庙旺利陷、小限、三台八座等杂曜、飞星四化。
