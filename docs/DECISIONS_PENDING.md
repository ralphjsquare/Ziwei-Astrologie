# 待你裁决的两个默认值（ADR-010 的延伸说明）

## 1. 闰月规则（`leapMonthRule`，当前默认 `midMonth`）
- 问题：出生在农历闰月时，闰月出生的人算“上个月”还是“下个月”定命宫？
- 三个选项：`midMonth`（闰月前半月按本月、后半月按下月，即“月中分界”，现代最通行）、`currentMonth`（一律按本月）、`nextMonth`（一律按下月）。
- 《紫微斗数全书》卷二原文写“闰月一律按下月”，即 `nextMonth`；但它是明代刻本的说法，现代主流软件（含参照实现 iztro）默认 `midMonth`。
- 影响：只影响闰月出生者（约每 3 年有一个闰月，即约 3%–4% 的出生日期）；命宫与十二宫随之整体移位，性格与事业等解读会完全不同。
- 现状：三种规则都可在界面切换，默认 `midMonth`；每张盘旁边会标出所用规则。
- 建议：保持 `midMonth` 默认（与黄金盘参照实现一致），在界面里对闰月出生者提示“规则不同结果不同”，并附全书原文。若你想以古籍为准，把默认改为 `nextMonth`，需同步重生成黄金盘（闰月用例）。

## 2. 大限诀的措辞与首个大限起点
- 全书《大限诀》原话是：“阳男阴女从命前一宫起顺行，是父母宫；阴男阳女从命后一宫起逆行，是兄弟宫”。字面读法是首个大限落在命宫的前/后一宫，而不是命宫本身。
- 现代通行做法（iztro 等）：首个大限从命宫起，按阳男阴女顺行、阴男阳女逆行，每 10 年一宫，起岁数为五行局数。
- 影响：所有大限的宫位错开一格，流年“大限四化”“大限落宫”的解读随之变化，几乎影响所有盘。
- 现状：采用通行做法（命宫起），并在 ADR-010 记录了原文歧义；未做成开关。
- 建议：保持现状，但把“字面读法”作为选项加入设置（`decadeStart: 'ming' | 'literal'`），默认 `ming`。若你同意我就实现；不同意就仅保留 ADR 记录。
