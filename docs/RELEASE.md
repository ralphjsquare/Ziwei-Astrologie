# 1.1.0 发布说明与收尾清单（2026-10-03）

> 1.1.0 相对 1.0.0：外部成熟软件对照验证（ADR-020；命主／身主、各柱旬空、将星／华盖不计本柱）、可读性功能（一页读懂、名词词典、图形，ADR-021）、长生／博士／将前／岁前十二神与子斗。计算结果新增字段，存档重算会提示“引擎版本变化”。

## 交付物
| 交付物 | 生成方式 | 说明 |
|---|---|---|
| 网页版 | `npm run build` → `dist/` | 需静态服务器（或桌面版）；数据只存浏览器本地 |
| 单文件 HTML | `npm run build:html` → `release/ziwei-bazi.html` | 双击即可在浏览器打开，约 1.2MB，无需联网 |
| Windows 桌面版 | `npm run desktop:win` → `release/ZiweiBazi-win32-x64.zip` | 免安装；exe 无代码签名，见 `docs/DESKTOP.md` |
| 神煞规则审阅包 | `npm run pack:shensha` → `docs/packages/神煞规则包.zip` | 78 条神煞规则的总表、明细、审核表 |
| 全量校验 | `npm run verify` | 类型检查、纯度检查、来源检查、298 个测试（含浏览器端到端） |

## 功能范围
紫微（三合派）与八字排盘；一页读懂总览、名词词典、五行／十神／大运大限图形；四组十二神与子斗；流年、流月、大限、小限、大运；紫微×八字并列对照；合盘；解读（每条附出处、白话、依据等级、审核状态）；本地存档与重算校验；审核文档导出与导回；神煞 78 种；庙旺利陷；调候参考；无古籍引文的规则明确标注。

## 已验证
- 历法：香港天文台 1901–2100 逐日对照（含 2057 年的一处官方例外）。
- 独立实现比对：iztro（紫微，含闰月、大限、小限、庙旺）、tyme4ts、寿星天文历 sxtwl（60 个黄金盘四柱）、bazi-lite、js-ephemeris-lite、ziwei-lite、mingyu-core（表格参照）。
- 古籍：《紫微斗数全书》《三命通会》（卷一至十二）逐条引文校验；《三命通会》引文与 Kanripo 文渊阁四库本机械核对，异文已标注。
- 确定性：浏览器与 Node 对同一输入的计算结果逐字节一致；同一输入多次计算一致。

## 已知限制（需要知情）
1. **所有规则仍是“未审核（draft）”**：没有专业老师审核；黄金盘的“人工核对”是用户采纳 AI 预核记录（`docs/golden/AI_PRECHECK_SHEET.md`）。
2. **引文底本未核实**：语料来自维基文库转录本与用户提供的电子书（版本未核实），须对照影印本；尚有“申子辰/申子申”“脆/胞”两处字形待核。
3. **子平真诠、渊海子平、穷通宝鉴、滴天髓**：电子转录本、版本未核实，只摘录被引用的部分。
4. **暂缓的神煞**：官符、病符、死符、日刑、流血、剑锋、天刑、雷霆、吞陷、浮沉、返本、短寿（原文判据不完整或自相矛盾，见 ADR-019）。
5. **未实现**：飞星派；桌面版仅 Windows，且未在真实 Windows 上运行过；exe 无代码签名。
6. 神煞、格局等只列“位置/候选”，不打分、不作吉凶结论；解释均为传统说法整理，仅供文化研究与参考。
7. 成本台账 `docs/LEDGER.md` 需要使用者自行填写实际花费（开发环境看不到用量）。

## 冻结的口径（见 ADR）
闰月 midMonth；首限落命宫，阳男阴女顺、阴男阳女逆；八字不设闰月规则；日界 23:00 起算次日；文昌与红艳默认《三命通会》表（可切换通行表）；阴干羊刃默认关闭；辛年魁钺默认“虎马”；壬年四化默认“府”。
