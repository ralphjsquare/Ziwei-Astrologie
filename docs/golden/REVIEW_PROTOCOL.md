# 黄金盘人工核对方法（最佳实践）

**目的**：黄金盘是“标准答案已知”的测试命盘。标准答案**不能**来自本软件自己，否则永远“正确”。这里的人工核对，是让一位懂行的人（你本人或老师）按传统方法独立推一遍，再与本软件比对。

## 一、独立来源（核对时用，而不是本软件）
1. **公历↔农历、节气**：香港天文台“公历与农历日期对照表”与“二十四节气”；紫金山天文台《中国天文年历》；两者取其一即可，最好再对一个纸质万年历。
2. **紫微安星**：《紫微斗数全书》安星诀（安紫微星诀、安命宫身宫、五行局、四化、六吉六煞诀）。用公版电子文本或影印本。
3. **八字**：节令时刻以上面的天文台数据为准；日柱用可靠万年历；大运起运用“三天折一岁”。

## 二、每盘的核对步骤（`HUMAN_REVIEW_SHEET.md` 中已列出本软件的推演供对照）
**紫微**
1. 查得出生当日的农历年、月、日（闰月按所选规则处理）；年干支以正月初一换年。
2. 定命宫：寅宫起正月，顺数到生月，再从该宫起子时逆数到生时；身宫同月位起子时顺数到生时。
3. 五虎遁定各宫天干；由命宫干支查纳音，得五行局。
4. 安紫微：用局数除农历生日，余数不足以整除则“借数”补到整除，商数从寅宫起数，借数奇则逆行、偶则顺行；再按诀安其余主星。
5. 依年干查四化；依年干、年支、月、时安辅佐煞曜；依阴阳男女定大限顺逆，局数为起限岁数。
**八字**
1. 年柱以立春为界，月柱以节令为界（精确到时分，与天文台数据核对）；日柱查万年历；时柱用五鼠遁。
2. 阳男阴女顺排、阴男阳女逆排大运；数到下一个（或上一个）节令，三天折一岁、一日四个月、一时辰十天。

## 三、判定与记录
- 每一项都与本软件一致，才算该盘“通过”；任何一项不一致，**先不要改软件**，把不一致的项目、你的推演、所用来源一并记录，交给开发者查因（可能是软件错误，也可能是流派并存的说法，如辛年魁钺、部分天干四化）。
- 建议**两人独立核对**同一批盘，或至少对有争议的盘请第二人复核。
- 通过后运行：`npm run golden:sign -- G01 G02 … --by 姓名`，签字会写入 `test/fixtures/golden.json`（重新生成固件时会保留）。
- 完成 20 个代表盘的核对后，才可在 README 中把“黄金盘人工核对”标为完成。
- 工时估计：每盘 10–20 分钟，20 盘约 4–6 小时（不计入 API 预算）。

## 四、AI 预核与人工核对的区别（2026-09-29）
- `oracle.aiPrecheck`（role=`AI_INDEPENDENT_PRECHECK`）：AI 依独立资料与规则的预核记录，见 `AI_PRECHECK_SHEET.md`；20/20 通过，未发现需要修改期望值的项目。我方对该记录做过抽查，结论一致；其所称的外部站点是否被实际查阅无法证实。
- `oracle.humanVerifiedBy`（role=“本人（非专业）”）：只有人自己用外部工具核对并勾选 `INTERACTIVE_REVIEW.md` 后才写入。目前 0/20。
- 二者互不替代；README 与解读页不得把 AI 预核写成“人工核对完成”。
