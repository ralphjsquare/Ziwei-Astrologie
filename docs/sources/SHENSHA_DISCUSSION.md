# 神煞：需要交流确认的事项

以下是我不敢自己拍板的神煞取舍。每项列出：原文（语料中的逐字引文）、其他实现的取法、可选方案和我的建议。请在选项前把 `[ ]` 改成 `[x]`，然后发回给我，我来落地。

所有原文均来自维基文库转录本（版本未核实），所有规则都是 draft；“其他实现”指 bazi-lite、mingyu-core 两个开源库，它们只是参照，不是古籍。

## 1. 天德贵人 / 天德合

原文只给出前四个月，其余月份来自两个软件实现。要不要收？

**原文**

> 《三命通会》卷三·论天月德：「天德合，如正月丁与壬合，二月坤与巽合，三月壬与丁合，四月辛与丙合，余照此」
> 《三命通会》卷三·论天月德：「此十二位宫，能回凶作善，乃曰天德也」

**其他实现的取法**

实现（mingyu-core 与 bazi-lite 一致）：正月丁、二月申（坤）、三月壬、四月辛、五月亥（乾）、六月甲、七月癸、八月寅（艮）、九月丙、十月乙、十一月巳（巽）、十二月庚。原文前四个月与之相符，后八个月原文只泛称“十二佐宫”而无逐月表。

**可选方案**

- [ ] A. 收：全表照实现，规则注明“前四个月有原文，其余取通行表”（S1-A）
- [ ] B. 收：只收原文明示的前四个月（S1-B）
- [ ] C. 不收（S1-C）

**我的建议**：收全表，注明来源分级；有 bazi-lite 可逐盘比对。

## 2. 文昌贵人

原文歌诀与通行表不是同一张表。要选哪一张？

**原文**

> 《三命通会》卷三·论太极贵：「有文昌贵，甲乙蛇口乙猪头，丙狗丁龙戊向猴；己午庚寅辛未贵，六壬卯位癸逢牛」

**其他实现的取法**

原文歌诀读法（mingyu-core 的“非文枕”表与之相符）：甲巳、乙亥、丙戌、丁辰、戊申、己午、庚寅、辛未、壬卯、癸丑。通行表（bazi-lite 与 mingyu-core 的“文枕”表）：甲巳、乙午、丙申、丁酉、戊申、己酉、庚亥、辛子、壬寅、癸卯。原文首句“甲乙蛇口”有讹字，只能靠对照实现来还原。

- [ ] A. 默认通行表，原文歌诀表作为可选项（与闰月规则的做法一致）（S2-A）

**我的建议**：默认通行表、原文表作选项：与主流软件一致，古籍口径可选；原文表因首句讹字，需在规则里标注“据实现还原”。

## 3. 太极贵人

**原文**

**可选方案**

- [ ] A. 收：全表照实现，规则注明“壬癸的申取通行表，原文未明写”（S3-A）
- [ ] B. 收：壬癸只取巳（S3-B）
- [ ] C. 不收（S3-C）

**我的建议**：收全表并注明。

## 4. 红鸾、天喜（年支系）

语料里没有这两个神煞的年支对照表；语料里的“天喜神”是另一种说法（按季节）。

**原文**

> 《三命通会》卷三·论天月德：「此外又有天喜神，春戊，夏丑，秋辰、冬未，遇者主欢欣」

**其他实现的取法**

通行做法（两个实现一致）：红鸾按年支，子→卯、丑→寅、寅→丑、卯→子、辰→亥、巳→戌、午→酉、未→申、申→未、酉→午、戌→巳、亥→辰；天喜为红鸾之对冲。这套通行表在语料中找不到出处。

**可选方案**

- [ ] A. 收：证据等级标“现代整理”，无古籍引文，明确写“语料中无出处”（S4-A）
- [ ] B. 收原文的季节式“天喜神”，不收年支系红鸾天喜（S4-B）
- [ ] C. 都不收（S4-C）

**我的建议**：收年支系，标“现代整理”，不配引文。这样不冒称古籍。

## 5. 学堂、词馆

判据依赖“命”的五行（纳音）和长生位，“命”指年柱还是日柱原文没说清。

**原文**

> 《三命通会》卷三·论学堂词馆：「长生乃学堂之正位，如金命见辛巳，金长生在巳；辛巳，纳音又属金是也」

**其他实现的取法**

bazi-lite 有“正学堂、正词馆、官贵学堂、日干学堂”等多种子类，各自取法不同；两个实现互不相同。

**可选方案**

- [ ] A. 只收“正学堂/正词馆”（干支纳音同为“命”之五行且落长生/临官）——先要定“命”取年柱纳音还是日柱纳音（S5-A）
- [ ] B. 不收，等有明确的取法再说（S5-B）

**我的建议**：不收，避免在取法不明时引入一条不可核实的规则。

**我的建议**：增加选项，默认关闭。
